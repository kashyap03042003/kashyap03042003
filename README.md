### 🔬 Featured Research & Projects

#### 1. [Reliable Agentic AI for Multi-Step Software Maintenance](https://github.com/kashyap03042003)
* **Stack:** Python, LLMs, Tool Use, Automated Testing, Experimental Design
* **Highlights:** Developed a sandboxed, tool-using AI agent for multi-step software maintenance featuring autonomous repository search, test execution, and human-in-the-loop approvals. 
* **Metrics:** Achieved a **78.4% task completion rate** (34.2% relative gain), a **91.5% post-patch test pass rate**, and a **42% reduction in regressions** while self-correcting logic flaws within an average of 4.2 iterations.

#### 2. [Offline RL for Energy-Efficient Building Control](https://github.com/kashyap03042003)
* **Stack:** Python, PyTorch, CQL, IQL, Reinforcement Learning
* **Highlights:** Implemented and compared Conservative Q-Learning (CQL) and Implicit Q-Learning (IQL) models against behavior-cloning and rule-based baselines using historical BMS data. Tested robustness under unseen weather distributions via Monte Carlo rollouts.
* **Metrics:** Reduced HVAC energy consumption by **18.5%** and operating costs by **21.4%**, while maintaining a strict **99.2% thermal comfort compliance rate**.

#### 3. [Vision Model Robustness & Calibration under Corruptions](https://github.com/kashyap03042003)
* **Stack:** Computer Vision, Vision Transformers, PyTorch, TTA
* **Highlights:** Investigated robustness and confidence calibration under distribution shift by benchmarking Vision Transformers and CNNs against severe image corruptions (CIFAR-10-C) using test-time adaptation (TTA).
* **Metrics:** Improved corrupted image accuracy by **26.5%** over static baselines while preserving high clean-data accuracy (**96.4% top-1**) and achieving a **41% reduction in Expected Calibration Error (ECE)**.

#### 4. [Privacy-Preserving Federated Learning for Oral Cancer Detection](https://github.com/kashyap03042003)
* **Stack:** Go, gRPC, Federated Learning, Differential Privacy, PyTorch
* **Highlights:** Developed a distributed federated framework using 25,000+ medical images with FedAvg, FedProx, and MimeLite aggregation across non-IID clients using Go and gRPC.
* **Metrics:** Achieved **85% classification accuracy** (closing within 8% of centralized upper-bound), a **98% federated round completion rate**, and integrated Differential Privacy guarantees.

#### 5. [Parameter-Efficient Fine-Tuning of Code Transformers for Defect Prediction](https://github.com/kashyap03042003)
* **Stack:** Transformers, CodeBERT, GraphCodeBERT, PEFT, LoRA, Hugging Face
* **Highlights:** Investigated PEFT of CodeBERT and GraphCodeBERT under limited data settings using LoRA and adapter configurations across strict project-wise splits.
* **Metrics:** Achieved **12.4% higher PR-AUC** and **9.1% higher F1-score** on unseen target projects while reducing training time by **68%** and GPU memory by **45%**.
